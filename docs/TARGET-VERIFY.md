## mpv 音源的离线频谱（QYP3-050，本机只能跑单测+真实 ffmpeg 半集成）

本机已用**真实 APE（5:21）+ 真实 mpv** 验证过时间轴对齐（结论见下），所以
下面只留"只能在目标机上看"的观感 / 性能 / 降级项，不必再验同步：

- 独立 `ffmpeg -ss 120` 解出的片段与全曲矩阵在偏移 0 处逐帧完全一致
  （平均绝对差 0.0），偏移 ±1 帧即明显分叉 → 矩阵时间轴就是文件绝对时间轴
- 真实 mpv：`time-pos` 起播 0.076s、推进 0.9987× 墙钟；`duration` 321.668s
  vs 矩阵 321.667s（差 1ms）
- 渲染层 1Hz 锚点 + 线性外推的取帧误差 ≤ 1 帧（≈83ms）且帧号不回退

- [ ] **有 ffmpeg 时**：播一首非直解格式（本地 APE / WebDAV 的冷门格式 / Emby 上
      codec 非直解的曲目）→ 起播后几秒内底部的频谱开始跳动（不再是静音底线），
      暂停时冻结在最后一帧，seek 后频谱与声音重新对齐
- [ ] 老机 CPU：解码期间播放不卡顿、不掉帧（并发 1、起播 3s 后才开工）；
      一首 5 分钟的歌后台解码应在十几秒内结束（本机实测 ~1s，老机按 10-20× 估）
- [ ] 缓存：`~/.config/qy-player/music-spectrum/` 出现 `*.qys`（一首 4 分钟 ≈138KB）；
      诊断摘要里能看到 `music-spectrum` 分区；删掉目录后下次播放会重算
- [ ] **没有 ffmpeg 时**（把 PATH 里的 ffmpeg 藏起来，或目标机本就没有）：
      频谱回到静音底线，别的功能一切正常，没有报错弹窗、主进程 stdout 无噪音

## 音效调节（QYP3-068v，本机无声卡/无耳机，必须实机听）

- [ ] 声场：宽度拉到 0 → 声音收成单声道感；拉到 2 → 明显更宽（注意听是否
      有相位导致的中空感）；平衡拉到一端 → 只有一边有声
- [ ] 交叉馈送（戴耳机听）：拉到 100% → 左右声道明显向中间靠、贴耳感变弱。

      mpv 是完整实现），这不是 bug
- [ ] 频段增删：加到 10 段后「添加频段」置灰；删到 0 段后声音应回到未处理的

- [ ] 设置页「音乐」页签点「打开音效面板」能打开同一个面板（编辑入口只有
      这一处）
- [ ] 与频谱的关系：改 EQ 时拾音器画面**不该跟着变**（采样点在 EQ 之前，
      离线频谱与在线拾音器都算原始 PCM）；若改 EQ 后柱子整体变矮/变高，
