## 音乐（三期，v1.2.0 增补）

- [ ] 本地 / WebDAV 音频扫描：标签（ID3v2/FLAC/m4a）入库、内嵌封面显示、
      CUE 分轨（strict：引用缺失则整张不入库）
- [ ] 封面格式覆盖：**内嵌封面是 JPEG 的专辑/歌手要有图**（此前只有 PNG
      夹具走过，真实 MP3 的 APIC 多为 image/jpeg；修的是这条分支）
- [ ] 需认证的 WebDAV 音频要能出声（此前认证头会话漏传 → mpv 静默 401，
      连错误提示都没有；同一来源的视频播放一直正常，可作对照）
- [ ] 双引擎播放：常见格式（mp3/flac/m4a…）走内置引擎；冷门格式
      （ape/wma/dsf…）走 mpv；曲间 gapless 无爆音（实听）
- [ ] 迷你控制条 / 全局媒体键：上下曲、播放暂停、歌词面板开合
- [ ] 桌面歌词（GNOME/X11）：透明生效（**若黑底则记录为降级项**）、
      置顶、鼠标穿透（锁定）/ 解锁拖动、位置与字号重启后恢复
- [ ] 性能保护（QYP3-036）：播放音乐时用其它程序把 CPU 压满 → 频谱图刷新明显变慢
      （帧率下降但仍在动），压力回落后自动恢复流畅；精简浮窗的仪表按钮与「设置 →
      音乐」的开关都能即时生效，关掉后即使 CPU 满载也不再降帧；关掉开关再制造压力，
      对比确认开着时播放更不卡（降帧确实把 CPU 让给了音频）
- [ ] 精简模式浮窗（QYP3-035）：播放音乐时点迷你条「精简」→ 主窗口缩成屏幕
      右上角置顶小浮窗，显示频谱图 + 进度 + 上一曲/暂停/下一曲 + 循环/随机 + 音量；
      拖动进度可跳转、音量与循环即时生效；点浮窗「还原」恢复原尺寸（原位置/可缩放）；
      设置里开「播放音频时自动进入」后起播自动缩窗；音乐会话结束（或开始放视频）
      自动还原，不把用户困在空小窗；多显示器下缩到窗口所在屏的右上角
- [ ] 拾音器：实时频谱与**真实波形**切换；30fps 下的 CPU 占用采样（老机预算）
- [ ] 播放频谱图（QYP3-034）：音乐页顶部在有音乐会话时常驻；本地音轨在**柱状**
      与**瀑布**两种图表下都随音调实时跳动，切换后记住选择（重启仍在）；服务器 /
      WebDAV 等 mpv 音源显示"无法显示真实频谱"提示（不画假数据）；切视图/切来源
      时频谱区常驻；30fps 下瀑布图 CPU 占用可接受（老机预算）
- [ ] 拾音器**真波形**（QYP3-033）：本地普通音轨（mp3/正常 flac）在 waveform /
      spectrum 模式都出现随音调起伏的**真实**波形/频谱；嘲笑.flac 这类
      `METADATA_BLOCK_PICTURE` 非法的 FLAC 不再被兜底到 mpv，应在内置引擎出
      **真波形**且不弹 mpv 窗口（非法封面被剥离后重播）；服务器/WebDAV/CUE 等走
      mpv 的音源拾音器显示**静态进度线**（诚实告知无真实波形，绝不计假跳动正弦波）
- [ ] 音乐经 mpv 解码**不得弹出 mpv 视频窗口**（QYP3-032）：本地冷门格式 /
     服务器 / WebDAV / 内置引擎兜底（如内嵌封面非法的 FLAC）的音乐播放时只走
     底部迷你条，不应出现独立 mpv 窗口（音频文件内嵌封面会被 mpv 当成 video
     轨，必须 `vid=no` + `force-window=no` 压窗）；视频播放仍应有 mpv 窗口；
     音乐→视频→音乐切换窗口状态正确
- [ ] 歌单：新建/重命名/删除/排序、m3u8 与 XSPF 导入导出往返
- [ ] 服务器音乐（Jellyfin/Emby）：音乐页来源切换出现服务器的音乐库；
      专辑→曲目→播放出声；播放中上下曲在服务器队列内推进（队尾停止，
      不回卷到第一首）；非音乐库（电影/剧集）与未登录服务器不出现在来源里
- [ ] 引擎切换与互斥：mpv 引擎音乐（服务器曲目 / 冷门格式）下迷你条出现、
      进度条与时间跟随、拾音器为波形；此时播放一个视频 → 音乐条消失、
      没有两路声音同时响；视频播放时迷你条不得出现
- [ ] 服务器曲目播放中按全局媒体键「下一曲」应是队列下一首（不是快进 30 秒）
- [ ] 服务器歌词：Jellyfin 上带歌词的曲目在歌词面板与桌面歌词同步高亮
      （服务器歌词无逐字标签 → 无卡拉OK 渐变属预期）；Emby 曲目显示
      "服务器上没有这首曲目的歌词"；面板对服务器曲目不显示「导入歌词」
- [ ] 服务器歌单：歌单页切到「服务器歌单」应列出已激活服务器上的歌单
      （未激活的服务器不出现）；点开能看到条目、点曲目出声且队列只含
      音轨；界面上找不到任何新建/重命名/删除入口

- [ ] 兜底路径：服务器上冷门格式（如 ape）曲目能自动回退 mpv 播出声（队列

      走 mpv 且不弹窗
- [ ] 主进程 stdout 无新增噪音：qy-stream 代理不应逐请求打日志
