# 二期运维说明（PHASE2-OPERATIONS）

面向用户/运维的运行时说明。对应 QYP2-026～037 交付的能力。

## 1. 插件与刮削

- **TMDB**：设置 → 插件 中填入自己的 TMDB v4 Read Access Token（仅存
  SecretStore，可从设置页测试健康状态；401→需要重新配置，429→稍后重试）。
  Token 只走 Bearer 头，不出现在 URL/日志/缓存键。
- **刮削**：详情页「刮削元数据」单项；媒体库目录页「批量刮削」（≤500/批，
  并发 2）。置信度 ≥0.92 自动应用；0.75–0.92 进人工确认队列；<0.75 不动。
  人工锁定字段（元数据编辑器）永不被刮削覆盖。
- **任务页**（导航「刮削任务」）：进度、取消、失败后恢复剩余条目；
  上游结构变化（UPSTREAM_CHANGED）自动暂停整批，适配后可恢复。
- **豆瓣**：实验路径，默认关闭且**不可启用**（ADR-0006 发布门禁未签认）。
  UI 不出现豆瓣入口，零网络请求。人工产品/法律/技术评审通过前保持该状态。

## 2. 缓存

| 分区 | 位置 | 策略 | 清扫 |
|---|---|---|---|
| 技术信息 probe | 内存 | LRU + TTL 6h，按内容指纹失效 | 自动，失败永不缓存 |
| 插件响应 | `userData/scrape-cache/` | mtime-LRU（读即续命）+ TTL 7 天，4096 条 | 自动驱逐 |
| 图片 | `userData/images/` | mtime-LRU，配额清扫 | `CacheManager.sweep` |
| **人工字幕** | `userData/subtitles/<itemId>/` | — | **受保护，永不清扫** |

## 3. 并发与速率预算（§16.4，常量单源 `cache-manager.ts`）

| 场景 | 上限 |
|---|---|
| 本地扫描 | 8 |
| WebDAV 扫描 | 4 |
| mpv probe | 1 |
| 刮削 | 2 |
| 事件推送 | ≤4Hz |
| 列表单页 | ≤200 |

## 4. 续播与自动连播

- 续播规则单源：`playback-state/resume-resolver.ts`（30s 有效门槛、90% 完成、
  看完→下一集→重播；0/null 不覆盖历史）。
- 自动下一集：仅自然 EOF 触发，5s 倒计时可取消；设置 → 播放可关闭
  （`app_config playback.autoNext`）。手动停止/崩溃/断开/退出不触发。
- 「从头播放」显式 0 起播，不清除历史。

## 5. 诊断摘要

诊断快照可安全分享：API key/token/凭据已打码；服务器地址只保留协议
（主机名整体 `***`）；缓存分区不出现绝对路径。导出前无需手工检查，
但如见异常字符串请反馈。

## 6. 回滚说明

- 数据库 migration 只追加不改写；回滚应用版本时旧库保持可读
  （schema_version 向前兼容由迁移数组尾部追加保证）。
- 插件缓存可整目录删除（`scrape-cache/`），下次刮削自动重建。
- 字幕目录删除即丢失人工字幕——删除前确认。
- 若 mpv probe 异常，probe 结果永不缓存失败，重启即重试；播放不受影响。
