# QY Player 二期开发计划（v1.1.0）

> 一期（v1.0.0）已完成：MPV 内核播放、Jellyfin/Emby 浏览/搜索/详情/播放、进度双向同步、观看历史、快捷键配置页。项目约束见根目录 `AGENTS.md`，本计划不重复，仅引用。

## 目标

把「能播」升级为「好用追剧」：补齐连续播放、播放器内控制（音轨/字幕/倍速）、收藏与继续观看闭环，并让设置覆盖播放器常用参数。所有改动不得触碰 `AGENTS.md` 中的硬性约束。

## 范围

### P0 — 追剧核心（M1 + M2）

**M1 连续播放与播放队列**
- 剧集播完自动连播下一集（结束前 15s 弹倒计时提示，可取消）
- 队列上下文贯穿主进程：Detail 页进入播放时携带全集列表，主进程解析下一集（含跨季）
- 手动"下一集/上一集"（播放窗口 + 托盘菜单）
- MediaNextTrack/MediaPreviousTrack 多媒体键语义改为 队列下一集/上一集，长按/无队列时回退为 快进/快退 30s（保持一期行为兜底）
- 验收：连播 3 集（含跨季边界）进度各自落库并同步服务器；Esc 取消连播不误触发

**M2 播放器控制完善**
- 应用内音轨/字幕选择 UI（`player:get-tracks` 已有，补 set-track IPC + 播放中面板），替代裸 uosc 菜单
- 倍速播放 0.5x–2x（播放窗口 UI + `[` `]` 快捷键），倍速记忆为会话级
- 截图增强：自定义保存目录（设置页），截图成功 Toast 带文件路径
- 验收：播放中切换音轨/字幕不中断播放；倍速在软解下无音画不同步（验证 1.5x 长播 10 分钟）

### P1 — 媒体库体验（M3）

**M3 继续观看 / 收藏 / 历史增强**
- Home 顶部「继续观看」行：本地 `playback_progress` + 服务器 ContinueWatching 合并去重，带进度条
- 收藏：海报卡片角标 + Detail 页按钮，同步服务器 Favorite 状态（Emby/Jellyfin `/Users/{id}/Favorite/{itemId}`）
- History 页：分页（20/页）、按类型筛选、点击条目直接续播
- 验收：收藏状态在服务器与本地间双向一致；继续观看行清除已看完条目

**M3.5 设置页扩展**
- 播放参数组：截图目录/格式、音量步进、启动时恢复上次服务器
- 全部持久化到 `app_config`（复用 `settings:get/set` 通道，禁止为每个选项新开通道）

### P2 — 锦上添花（视时间取舍）

- 检查更新：调 GitHub Releases API 比对版本，有新版 Toast 提示（不做自动更新）
- 音乐库浏览（Audio 类型 item 的列表 + 播放）
- 章节跳转（服务器返回 Chapters 时显示章节列表）

## 非目标（二期明确不做）

- 弹幕、直播/IPTV、转码画质选择器（直连优先策略不变）
- 自动更新安装（只提示）
- Windows/macOS 支持
- MPV 升级或硬解码开关（见 AGENTS.md 硬性约束 1、2）

## 风险

1. **连播与进度保存的竞态**：eof → 保存旧集进度 → loadfile 下一集，`PlaybackStateManager.setCurrentMedia` 必须在 loadfile 前完成，避免新集进度写到旧 media_id（一期 `time-pos: null` bug 的近亲，写 M1 时先设计状态机再动手）
2. **Emby vs Jellyfin API 差异**：收藏接口路径不同（`/emby` 前缀），复用 client 继承结构，不写两份
3. **老机器性能**：连播预加载只预解析元数据，禁止预加载视频流（软解 + 老缓存配置扛不住）
