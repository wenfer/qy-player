# 技术实现计划：QY-Player

## 1. 实现顺序

按能力映射图的依赖关系，采用**垂直切片**方式分阶段交付。每个阶段结束时有可运行的里程碑版本。

### 阶段 M1：基础骨架（Week 1）
**目标**：Electron + React + TypeScript 开发环境跑通，MPV 进程可启动并通信。

- 搭建 Electron 21 + Vite 多进程构建体系（main / preload / renderer）
- 配置 TypeScript 严格模式、ESLint、路径别名
- 实现 MPV JSON IPC 客户端（Unix Socket 连接、命令发送、事件监听）
- 实现 MPV 进程管理器（启动、健康检查、异常重启、优雅退出）
- 搭建 SQLite 数据库连接与 Schema 初始化
- 实现类型安全的 IPC Bridge（preload + 主进程 handler 注册框架）
- **验证**：运行 `npm run dev` 后，Electron 窗口显示 React 页面，点击按钮能启动 MPV 并加载视频

### 阶段 M2：本地播放能力（Week 1-2）
**目标**：支持本地视频播放、字幕加载、进度保存。

- 实现 Player Core 的完整播放控制 API（播放/暂停/Seek/音量/全屏）
- 实现播放状态监听与 IPC 广播到渲染进程
- 实现 Subtitle Engine：同目录字幕扫描、语言识别、自动加载
- 实现 Playback State：定时保存进度、断点续播、观看历史
- 实现 Settings 的数据层：SQLite 配置读写
- 构建播放控制 UI 组件（播放条、音量、字幕切换、时间显示）
- **验证**：选择本地视频 → 在 MPV 中播放 → 外挂字幕自动加载 → 暂停后关闭 → 重新打开恢复进度

### 阶段 M3：海报墙与本地播放入口（Week 2-3）
**目标**：Jellyfin/Emby 海报墙展示 + 本地文件快速播放入口。

- 实现轻量级本地文件浏览：打开文件/文件夹、列出视频文件
- 实现最近播放记录页面
- 构建 Jellyfin/Emby 海报墙首页：继续观看、最近添加、电影/电视剧分类
- 构建详情页：背景图、海报、简介、演职员、播放/续播按钮
- 构建搜索页（搜索在线服务器内容）
- 构建本地入口页：打开文件/文件夹快捷按钮 + 最近播放列表
- **验证**：连接 Jellyfin → 首页显示服务器海报墙 → 点击进入详情 → 点击播放 → 本地文件通过"打开文件"正常播放

### 阶段 M4：在线服务接入（Week 3-4）
**目标**：支持 Jellyfin/Emby 服务器接入与播放。

- 实现 Jellyfin API 客户端：发现、认证、视图、项目列表、详情
- 实现 Emby API 客户端（复用 Jellyfin 基类，覆盖差异点）
- 实现在线服务器配置 UI：添加服务器、测试连接、选择用户
- 实现混合海报墙：本地与在线库统一展示
- 实现在线流媒体 URL 构建与分辨率选择逻辑
- 实现 MPV 加载网络 HLS/DirectPlay URL
- 实现在线内容的进度同步（播放后上报服务器，可选）
- **验证**：添加 Jellyfin 服务器 → 浏览服务器媒体库 → 选择影片 → 选择 720p → MPV 播放

### 阶段 M5： polish 与打包（Week 4-5）
**目标**：UI 打磨、性能优化、Deepin 打包。

- 实现系统托盘与最小化到托盘
- 实现全局媒体快捷键（MediaPlayPause 等）
- UI 动画与过渡优化（骨架屏、图片懒加载、虚拟滚动）
- 错误处理与用户通知（toast 通知网络错误、服务器连接失败等）
- 性能优化：海报墙虚拟滚动、大数据量分页、图片懒加载
- 配置 electron-builder 生成 `.deb` 包
- 编写安装脚本与 desktop 入口
- 编写用户 README
- **验证**：在干净 Deepin 环境安装 .deb → 运行 → 完整走通本地+在线播放流程

## 2. 技术风险与缓解策略

| 风险 | 影响 | 概率 | 缓解策略 |
|---|---|---|---|
| Electron 21 在 Debian 10 上 GPU 渲染异常 | 高 | 中 | 启动参数加 `--disable-gpu` 或 `--no-sandbox` 降级；UI 以 CSS 为主减少复杂渲染 |
| MPV IPC Unix Socket 连接不稳定 | 高 | 低 | 实现连接重试（最多 3 次）、心跳检测、进程崩溃自动重启 |
| better-sqlite3 在 Electron 21 下编译失败 | 高 | 中 | 使用 `electron-rebuild` 针对 Electron Node 版本重编；备选 `sqlite3` + worker threads |
| 服务器网络不通或响应慢 | 中 | 中 | 实现请求队列与退避重试；支持用户配置代理；离线时显示缓存内容和错误提示 |
| Jellyfin/Emby 版本差异大 | 中 | 中 | API 调用增加版本兼容性检查；核心路径使用两者共通的 API 子集 |
| 大目录扫描阻塞主进程 | 中 | 中 | 文件夹浏览逻辑分片异步执行；渲染进程显示加载状态 |
| 服务器图片加载慢 | 中 | 中 | 图片使用 HTTP 缓存 + 懒加载；支持低分辨率缩略图参数 |

## 3. 里程碑定义

| 里程碑 | 交付物 | 验收标准 |
|---|---|---|
| M1 骨架 | 可运行的 Electron 空壳 + MPV IPC Demo | 点击按钮启动 MPV，发送命令返回响应 |
| M2 本地播放 | 本地视频播放 + 字幕 + 进度 | 完整播放一个带字幕的本地视频，关闭后恢复进度 |
| M3 海报墙 | 海报墙浏览 | 连接 Jellyfin/Emby，首页正确显示分类海报墙 |
| M4 在线接入 | Jellyfin/Emby 浏览与播放 | 成功连接测试服务器，播放至少一个在线视频 |
| M5 发行版 | `.deb` 安装包 + README | 在 Deepin 20.9 上安装并运行无报错 |

## 4. 验证检查点

每个阶段结束时执行以下检查：

1. **构建检查**：`npm run build` 无 TypeScript 错误
2. **代码检查**：`npm run lint` 无严重警告
3. **功能演示**：在 Deepin 实机或当前环境演示该阶段核心功能
4. **日志审查**：主进程控制台无未处理异常
5. **资源审查**：播放结束后 MPV 进程已退出，无僵尸进程
6. **在线验证**：断开网络后海报墙有合理的错误提示（非白屏）
